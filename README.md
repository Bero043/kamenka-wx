# Каменка · температура

Одностраничный сайт: текущая температура воздуха в Каменке (Приморский район, Санкт-Петербург).

- Данные — публичное API [Open-Meteo](https://open-meteo.com) (без ключа, без бэкенда).
- Координаты: `60.045, 30.243`.
- Обновление каждые 5 минут и при возврате на вкладку.
- Один файл `index.html`, никаких зависимостей.

## Локально

```bash
python3 -m http.server 4321
```

Затем открыть http://localhost:4321
