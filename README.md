# Kamenka · Petrogradka

Одностраничный сайт: температура и ветер в двух районах Санкт-Петербурга — Каменке и Петроградке.

**https://bero043.github.io/kamenka-wx/**

## Как это работает

- Данные — публичное API [Open-Meteo](https://open-meteo.com): без ключа, без бэкенда. Обе точки приходят одним запросом (`latitude=60.045,59.96&longitude=30.243,30.31`).
- Погода обновляется раз в 5 минут.
- Иконка выбирается по `weather_code`: солнце, облако или облако с дождём.
- Стрелка показывает, **куда** дует ветер (`wind_direction_10m + 180°`), и плавно пульсирует. Цвет — по южной составляющей `cos(dir − 180°)`: южные румбы тёплые (оранжевый → красный к чистому югу), северные холодные (синий), восточные и западные нейтрально-серые.
- Вёрстка по мотивам блока офисов на [motherdesign.com](https://www.motherdesign.com/): название полужирным, рядом моно-подпись, пульсирующий элемент в третьей строке. Их шрифты (Basis / Basis Mono) лицензионные — здесь взята близкая бесплатная пара Space Grotesk + Space Mono.
- Один файл `index.html`, ни сборки, ни зависимостей кроме шрифтов.

## Локально

```bash
python3 -m http.server 4321
```

Затем открыть http://localhost:4321
