# Каменка · температура

Одностраничный сайт: температура воздуха в Каменке (Приморский район, Санкт-Петербург) и скорость ветра.

**https://bero043.github.io/kamenka-wx/**

## Как это работает

- Данные — публичное API [Open-Meteo](https://open-meteo.com): без ключа, без бэкенда, запрос идёт прямо из браузера. Координаты `60.045, 30.243`.
- Обновление каждые 5 минут.
- Оформления нет: системный шрифт и дефолтные цвета браузера, `color-scheme: light dark` — страница сама следует теме системы.
- Один файл `index.html` на 23 строки, меньше 900 байт. Ни сборки, ни зависимостей, ни внешних шрифтов.

## Локально

```bash
python3 -m http.server 4321
```

Затем открыть http://localhost:4321
