# Kamenka · Petrogradka

Одностраничный сайт: погода в двух районах Санкт-Петербурга, цена Brent и главная новость США за сутки.

**https://bero043.github.io/kamenka-wx/**

## Источники данных

Все три работают из браузера напрямую — CORS открыт, прокси и бэкенд не нужны.

| Что | Источник | Ключ |
|---|---|---|
| Температура, ветер, направление | [Open-Meteo](https://open-meteo.com), обе точки одним запросом | не нужен |
| Brent | [ISS Мосбиржи](https://iss.moex.com), фьючерс BR ближайшей серии | не нужен |
| Новость США | [Guardian Content API](https://open-platform.theguardian.com), секция `us-news` | нужен |

Про Brent: показывается ближайший торгуемый контракт — код серии не зашит, а выбирается из
`statistics/.../series.json?asset_code=BR` по дате экспирации, поэтому после экспирации подхватится
следующий контракт сам. Цена — `LAST`, по выходным `SETTLEPRICE`. Оба запроса вместе меньше килобайта.

Про новость: `order-by=newest` за последние 30 часов, дальше отбирается первая моложе 24 часов.
Ключ в коде — официальный тестовый `test` от Guardian, он для разработки и может отвалиться;
свой бесплатный (5000 запросов в день) выдаётся мгновенно на open-platform.theguardian.com.

## Оформление

Вёрстка по мотивам блока офисов на [motherdesign.com](https://www.motherdesign.com/). Их шрифты
(Basis / Basis Mono) лицензионные — здесь близкая бесплатная пара Space Grotesk + Space Mono.

Стрелка показывает, куда дует ветер (`wind_direction_10m + 180°`), и плавно пульсирует. Цвет — по
южной составляющей `cos(dir − 180°)`: южные румбы тёплые (оранжевый → красный к чистому югу),
северные холодные (синий), восточные и западные нейтрально-серые.
