# Каменка · температура

Одностраничный сайт: текущая температура воздуха в Каменке (Приморский район, Санкт-Петербург).

**https://bero043.github.io/kamenka-wx/**

## Как это работает

- Данные — публичное API [Open-Meteo](https://open-meteo.com): без ключа, без бэкенда, запрос идёт прямо из браузера. Координаты `60.045, 30.243`.
- Обновление каждые 5 минут, при возврате на вкладку и по кнопке.
- Фон генерируется на месте, без картинок: градиент неба + два слоя облаков на SVG-фильтре `feTurbulence`.
  Палитра зависит от фазы суток (день / сумерки по времени восхода и заката / ночь), плотность облаков — от реальной облачности `cloud_cover`.
- Один файл `index.html`, никаких сборок и зависимостей, кроме шрифтов Google Fonts (с системными фолбэками).

## Локально

```bash
python3 -m http.server 4321
```

Затем открыть http://localhost:4321
