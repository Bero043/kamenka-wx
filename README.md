# Kamenka · Petrogradka

Одностраничный сайт: температура и ветер в двух районах Санкт-Петербурга — Каменке и Петроградке.

**https://bero043.github.io/kamenka-wx/**

## Как это работает

- Данные — публичное API [Open-Meteo](https://open-meteo.com): без ключа, без бэкенда. Обе точки приходят одним запросом (`latitude=60.045,59.96&longitude=30.243,30.31`).
- Погода обновляется раз в 5 минут, часы — раз в 30 секунд (московское время берётся из `Intl`, а не из ответа API).
- Иконка выбирается по `weather_code`: солнце, облако или облако с дождём.
- Вёрстка по мотивам блока офисов на [motherdesign.com](https://www.motherdesign.com/): название полужирным, рядом моно-подпись, мигающее двоеточие в часах. Их шрифты (Basis / Basis Mono) лицензионные — здесь взята близкая бесплатная пара Space Grotesk + Space Mono.
- Один файл `index.html`, ни сборки, ни зависимостей кроме шрифтов.

## Локально

```bash
python3 -m http.server 4321
```

Затем открыть http://localhost:4321
